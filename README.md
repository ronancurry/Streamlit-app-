# Blackjack Trainer

## Ronan Curry


## App Description

Blackjack Trainer is a beginner-friendly app for learning the flow of blackjack and practicing decisions in a low-pressure setting. The planned app will let users play sample hands, review basic strategy guidance, and track practice results so they can build familiarity with the game.

## Intended Users

This app is intended for people who are new to blackjack or want a simple way to practice and understand common decisions. It is for educational practice, not real-money gambling.

## Planned Features

- Play practice hands against a simulated dealer.
- Get basic strategy suggestions for common hands.
- Track wins, losses, and pushes across practice sessions.

## Run Locally

Install the project dependency and start the app:

```bash
pip install -r requirements.txt
streamlit run app.py
```
